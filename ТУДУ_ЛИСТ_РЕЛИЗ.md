# AntyTILT — ТУДУ ЛИСТ РЕЛИЗ

Этот документ описывает обязательные работы для превращения текущего локального
MVP в постоянно работающий multi-user сервис, в котором каждый пользователь
подключает собственный биржевой аккаунт и получает независимую Risk Management
систему.

Актуальность плана: 2 октября 2026 года.

## Главная цель релиза

Публичная версия должна обеспечивать следующий сценарий:

1. Пользователь регистрируется и подтверждает email.
2. Подключает собственный API-ключ биржи.
3. Выбирает VST или live-среду.
4. Настраивает персональные правила RM.
5. Активирует профиль.
6. Сервер проверяет каждый ордер перед отправкой.
7. Отдельный RM-worker круглосуточно контролирует позиции пользователя.
8. Прямая сделка на бирже обнаруживается и проверяется теми же правилами.
9. Все действия, ошибки и блокировки сохраняются только в истории владельца
   аккаунта.
10. Сбой frontend или закрытие браузера не останавливают RM.

Отдельный сервер или отдельный бот для каждого пользователя не требуется.
Один кластер API и worker-ов должен обслуживать все аккаунты, разделяя их по
user ID и exchange account ID.

во всех RM-таблицах, истории и аудите; профили независимы; primary/unique/FK
ключи состояния переведены с `user_id + environment` на exchange account.

read/update/delete операции. Несколько BingX VST или Live-аккаунтов одного
пользователя теперь поддерживаются без смешивания счётчиков, позиций, событий,
защитных ордеров и истории. Локальный mutex также разделён по account ID;
Redis lock разделён по `exchange_account_id`, а освобождение и
продление выполняются только при совпадении owner token.
